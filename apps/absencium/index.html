Absencium.

A student organiser concept for missed-class notes, attendance, reminders, and keeping academic life together.

View releases ↗ Source code ↗

In development — check the repository for current release status.

What it aims to do

Academic life, in one place.

▤

Notes vault

Organise missed-class notes by subject and date, with written notes and page-photo attachments.

◷

Attendance

Track present and absent days, attendance percentages, and personal attendance patterns.

✓

Reminders

Keep assignment deadlines, homework, and tasks visible with date-based reminders.

▦

Calendar

See upcoming holidays and manage personal exceptions and important dates.

◌

Offline-first

The intended architecture prioritises local storage and everyday use without an account.

✳

Thoughtful design

A Material 3 Expressive-inspired interface with themes, rounded forms, and accessible interactions.
