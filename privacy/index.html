About this website

Skywa1ker404's Studio is a static website that presents software projects and links to their repositories, releases, and support pages. It does not provide visitor accounts or a first-party contact form in its current design.

Theme preference

The website may store your selected light or dark theme in your browser's local storage under the key site-theme. This preference helps the site remember your theme on later visits. If browser storage is unavailable, the site can still use a theme for the current visit.

GitHub release information

App detail pages request public release information from the GitHub API to display version names, release notes, APK filenames, download URLs, and published asset sizes. Your browser connects to GitHub to make that request. GitHub may process technical request data under its own policies.

Hosting providers

This website may be hosted by GitHub Pages, Cloudflare Pages, or both. Hosting and security providers may process technical information such as IP addresses, request metadata, and security logs. Their own policies govern their handling of that information.
